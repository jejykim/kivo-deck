# 개발 순서

## 0. 준비 (부품 도착 전)
- [x] Windows에 Git, VS Code, PlatformIO 설치 (pio는 `F:\pio_env`), Node · Rust · MSVC Build Tools
- [~] 로컬 git 저장소 만듦 — GitHub에 올리기는 5단계에서
- [x] `firmware`를 PlatformIO로 빌드 성공 (`pio run`)

## 1. 펌웨어 1단계 — ESP32 단독 테스트 (납땜 전)
- [x] 뒷면 USB-C로 업로드, PC가 키보드 + Consumer Control + COM 포트로 인식
- [x] 시리얼에 `{"cmd":"hello"}` → `hello` 응답, PC 앱이 자동 연결
- [~] PC 앱이 연결 시 번들 전송 → 보드에 키 화면 표시 확인 — 다시 연결해도 `bundle` 해시가 같은지는 남음

## 2. 조립 후 입력 확인
- [ ] 화면 15칸 표시, 방향(`DISPLAY_ROTATION`)·색 확인, 페이지 JPEG가 앱 미리보기와 같은지
- [ ] 터치 보정 → 15칸 각각 누르면 설정한 동작 (길게·두 번·토글 타이밍 확인)
- [ ] 노브(돌리기·누르기·누른 채 돌리기), 페이더 값 방향·0~1000 범위
- [ ] GIF 재생 속도, 여러 칸 이미지 이음매

## 3. PC 앱 (빌드·브라우저 미리보기로 확인, 실기기 확인은 남음)
- [x] 기기 자동 연결, 트레이, 로그인 시 자동 실행, 로그(왼쪽, 접힘), 시작 로고
- [x] OS별 프리셋 3칸, 다른 OS 프리셋 빌려 쓰기 + "사용 불가" 표시(앱·보드 화면)
- [x] 드래그앤드랍 편집: 키(누르기·길게·두 번·토글), 노브(돌리기·누르기·누른 채 돌리기), 페이더
- [x] 기능: 단축키·문자·매크로·미디어·볼륨(시스템/마이크/앱별)·사운드보드·열기·페이지·폴더·스톱워치, 앱별 기능(Photoshop·OBS)
- [x] 키 화면: 글자·이미지·GIF·영상→GIF·여러 칸 이미지(배치 추천)·제목 글자·실시간(시계·날짜·CPU·메모리·스톱워치)
- [x] 프로그램별 페이지 자동 전환, 화면 보호, 프리셋 파일 내보내기/가져오기
- [x] 업데이트 확인·설치 (GitHub 릴리스)
- [ ] 실기기로 확인: 페이더 볼륨, 앱별 볼륨, OBS, 자동 전환
- [ ] 프로그램 팩 늘리기 (사용자와 하나씩)
